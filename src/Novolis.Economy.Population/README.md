# Novolis.Economy.Population

Consumer cohort stubs. Demand is modeled per cohort, not per individual citizen.

Household math: `HouseholdMath.Count` / labor hours / comfort floor from headcount (`PeoplePerHousehold`, default 4). Cohorts carry `Productivity` (Common/Mean/Extreme) and optional `HouseholdFirmId`.

```bash
dotnet add package Novolis.Economy.Population
```
